    畢氏定理

在直角三角形中，直角所對的邊叫做斜邊，它一定是最長的邊；另外兩條邊叫做直角邊。

畢氏定理：如果直角三角形的兩條直角邊是 a 和 b，斜邊是 c，那麼 a² + b² = c²。

例一（求斜邊）：兩條直角邊分別是 3 cm 和 4 cm。c² = 3² + 4² = 9 + 16 = 25，所以 c = √25 = 5 cm。

例二（求直角邊）：一把 5 m 長的梯子斜靠在牆上，梯腳離牆 1.4 m。梯子是斜邊，所以要用減法：h² = 5² − 1.4² = 25 − 1.96 = 23.04，h = √23.04 = 4.8 m。

逆定理：如果三角形的三邊滿足 a² + b² = c²（c 是最長邊），那麼這個三角形是直角三角形。例如 9² + 12² = 81 + 144 = 225 = 15²，所以三邊為 9、12、15 的三角形是直角三角形；但 6² + 7² = 85，不等於 9² = 81，所以三邊為 6、7、9 的三角形不是直角三角形。

生活應用：想檢查一個角是不是直角，可以在一邊量 3 m、另一邊量 4 m，如果兩個記號剛好相距 5 m，那個角就是直角。

記得檢查答案：斜邊一定是最長的邊，直角邊不可能比斜邊長。
    p19 學生答案（含刻意錯誤，用於回饋示範）
    題目：一把 5 m 長的梯子斜靠在垂直的牆上，梯腳離牆 1.4 m。梯頂離地面有多高？

學生答案：
設梯頂高度為 h。
h² = 5² + 1.4²
h² = 25 + 1.96 = 26.96

    畢氏定理

在直角三角形中，直角所對的邊叫做斜邊，它一定是最長的邊；另外兩條邊叫做直角邊。

畢氏定理：如果直角三角形的兩條直角邊是 a 和 b，斜邊是 c，那麼 a² + b² = c²。

例一（求斜邊）：兩條直角邊分別是 3 cm 和 4 cm。c² = 3² + 4² = 9 + 16 = 25，所以 c = √25 = 5 cm。

例二（求直角邊）：一把 5 m 長的梯子斜靠在牆上，梯腳離牆 1.4 m。梯子是斜邊，所以要用減法：h² = 5² − 1.4² = 25 − 1.96 = 23.04，h = √23.04 = 4.8 m。

逆定理：如果三角形的三邊滿足 a² + b² = c²（c 是最長邊），那麼這個三角形是直角三角形。例如 9² + 12² = 81 + 144 = 225 = 15²，所以三邊為 9、12、15 的三角形是直角三角形；但 6² + 7² = 85，不等於 9² = 81，所以三邊為 6、7、9 的三角形不是直角三角形。

生活應用：想檢查一個角是不是直角，可以在一邊量 3 m、另一邊量 4 m，如果兩個記號剛好相距 5 m，那個角就是直角。

記得檢查答案：斜邊一定是最長的邊，直角邊不可能比斜邊長。
