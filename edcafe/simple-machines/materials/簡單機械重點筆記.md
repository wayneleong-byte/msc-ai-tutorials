# 簡單機械重點筆記（小學五年級常識科）

> 適用：小五常識「科學與生活」範疇。對應澳門《小學教育階段常識基本學力要求》D—2—10「能說明簡單機械的原理，並能舉出它們在生活中的應用」〔S1〕。
> 本筆記內容只根據文末「資料來源」整理，方括號〔S#〕為出處編號。

## 一、甚麼是機械？甚麼是簡單機械？

- **機械**：凡能使我們省力或得到方便的工具，都可稱為「機械」〔S2〕。
- 使用機械的三個目的：**省力**、**省時（加快速度、縮短移動距離）**、**改變力的方向（方便操作）**〔S2〕。
- **簡單機械**是構造簡單、只有很少或沒有活動部件的裝置，用來改變力的大小或方向，幫助我們做事〔S4〕。
- 常見的六種簡單機械：**槓桿、滑輪、輪軸、斜面、楔、螺旋**〔S4〕〔S7〕。
- 很多複雜的機械，都是由這些簡單機械組合而成〔S2〕〔S4〕。由兩種或以上簡單機械組成的叫**複合機械**，例如剪刀、削筆機、起重機〔S7〕。

> ⭐ 重要觀念：機械**不能省功**，也不會「變出」能量；它只能把力和距離互相交換——**省力就要多走距離，省距離就要多用力**〔S2〕〔S6〕。

## 二、槓桿

### 1. 定義和「三點」
**槓桿**是一根可以繞著一個固定點轉動的硬棒〔S2〕〔S5〕。槓桿上有三個重要位置〔S2〕〔S3〕〔S5〕：

| 名稱 | 意思 | 蹺蹺板例子 |
|---|---|---|
| **支點** | 槓桿轉動時繞著的固定點 | 中間不動的支架 |
| **施力點** | 我們用力（推或拉）的位置 | 你坐的一端 |
| **抗力點**（又叫受力點／重點） | 重物（負載）所在、阻礙轉動的位置 | 另一端的同學 |

- **施力臂**：施力點到支點的距離；**抗力臂**：抗力點到支點的距離〔S2〕。
- **施力臂比抗力臂長 → 省力**（但施力要移動較長距離）；**施力臂比抗力臂短 → 費力**（但移動距離短、較快）；兩者相等 → 不省力也不費力，只改變方向〔S2〕。
- 例子：撬棍的施力臂是抗力臂的 5 倍，力量就被放大約 5 倍〔S8〕。

### 2. 三類槓桿（看「哪一點在中間」）

| 類別 | 在中間的是 | 特點 | 生活例子 |
|---|---|---|---|
| **第一類** | **支點** | 可省力、可費力，視乎支點位置；常用來改變力的方向 | 蹺蹺板〔S6〕、剪刀、拔釘鎚〔S2〕；點頭時的頭頸〔S6〕 |
| **第二類** | **抗力點** | 施力臂一定較長 → **省力** | 手推車〔S2〕〔S6〕、胡桃鉗、開瓶器〔S2〕；踮腳尖〔S6〕 |
| **第三類** | **施力點** | 施力臂較短 → **費力**，但**省時、動作幅度大** | 鑷子、筷子、掃帚、彎曲手肘的手臂〔S2〕〔S6〕 |

記憶口訣（自擬）：**「一支、二抗、三施」在中間**。

## 三、滑輪

**滑輪**是邊緣有凹槽、能繞中心軸轉動的輪子，配合繩子使用〔S2〕〔S5〕。

1. **定滑輪**：滑輪的軸**固定不動**。它**不能省力**（拉力約等於物重），作用是**改變力的方向**，令操作方便〔S2〕〔S3〕。例子：升旗時向下拉繩、旗子向上升〔S5〕。
2. **動滑輪**：滑輪**隨重物一起上下移動**。它可看作施力臂是抗力臂兩倍的槓桿，拉力約為物重的**一半**，可以**省力**〔S2〕〔S5〕；但省力的代價是要拉動較長的繩子〔S2〕。例子：起重機的吊鉤〔S5〕。
3. **滑輪組**：把定滑輪和動滑輪組合起來。滑輪越多，提起重物所需的力越小〔S5〕；起重機、升降機等起重設備常用滑輪組合〔S3〕〔S5〕〔S8〕。

## 四、輪軸

- **輪軸**由一個大輪和一根小軸**固定在同一軸心上**、一起轉動〔S2〕〔S3〕。
- 輪軸其實是**槓桿的變形**：軸心是支點，輪的半徑和軸的半徑就像兩條力臂〔S2〕。
- **施力在輪上 → 省力**（但要轉較大的圈）；**施力在軸上 → 費力**，但移動距離短〔S2〕。輪的半徑是軸的半徑的倍數越大，就越省力〔S3〕〔S4〕。
- 生活例子：門的喇叭鎖（圓門把）、汽車方向盤、螺絲起子〔S2〕〔S4〕；水井的轆轤、絞盤〔S3〕。

## 五、斜面（以及楔、螺旋）

- **斜面**是一個傾斜的平面。把物件沿斜面推上高處，比直接垂直抬起**省力**〔S2〕〔S3〕〔S4〕。
- **斜面越長（坡度越小）就越省力**，但要走的距離越長；坡度越陡，所需的力就越接近物件本身的重量〔S2〕〔S3〕〔S4〕。
- 生活例子：斜道（例如貨車上落貨用的斜板）、樓梯、彎彎曲曲上山的公路〔S2〕〔S4〕〔S7〕。
- **楔（劈）**：兩個斜面合在一起，用來切割、分開物件，例如刀、斧頭、門牙〔S2〕；門擋也是楔〔S7〕。
- **螺旋**：把斜面圍繞在圓柱上，例如螺絲、有螺紋的瓶蓋、螺旋式千斤頂〔S2〕〔S4〕〔S7〕。

## 六、生活中的簡單機械小總結

| 物件 | 簡單機械 |
|---|---|
| 剪刀 | 第一類槓桿〔S2〕；NASA 指剪刀由兩種簡單機械組成，屬複合機械〔S7〕 |
| 開瓶器、手推車 | 第二類槓桿〔S2〕 |
| 筷子、鑷子 | 第三類槓桿〔S2〕 |
| 升旗旗桿 | 定滑輪〔S5〕 |
| 起重機吊鉤 | 動滑輪／滑輪組〔S5〕 |
| 喇叭鎖、方向盤、螺絲起子 | 輪軸〔S2〕 |
| 斜道、樓梯 | 斜面〔S2〕〔S7〕 |
| 刀、斧頭 | 楔〔S2〕 |
| 螺絲、瓶蓋 | 螺旋〔S2〕〔S7〕 |

## 七、常見誤解（及正確概念）

1. ❌「機械可以幫我們省功、製造能量。」✅ 機械不能省功，只能交換力和距離〔S2〕。
2. ❌「所有槓桿都省力。」✅ 第三類槓桿是費力的，好處是省時、動作幅度大〔S2〕〔S6〕。
3. ❌「定滑輪可以省力。」✅ 定滑輪不省力，只改變力的方向〔S3〕。
4. ❌「斜面越陡越省力。」✅ 斜面越長、坡度越小才越省力〔S3〕〔S4〕。
5. ❌「可以同時省力又省距離。」✅ 槓桿只能給我們「力量上的好處」或「動作上的好處」，不能兩者兼得〔S6〕。
6. ❌「機械一定要有引擎或用電。」✅ 簡單機械只有很少或沒有活動部件，例如一塊斜板、一根棒都是簡單機械〔S4〕。
7. ❌「輪軸在哪裏用力都一樣。」✅ 用力在輪上才省力，用力在軸上會費力〔S2〕。
