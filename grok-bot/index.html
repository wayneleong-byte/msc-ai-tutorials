⭐ Primary Bot（主入口 bot）：10 條規則（1–5）

Primary Bot＝日常入口／路由／閘／物證。每卡：做什麼 → 為什麼。

🎯
1. 一件事一句職責
做：只當入口與閘，不做所有 domain。
為何：避免雜訊與權限過大。
🌐
2. 繁中／時區／安靜
做：繁中、Asia/Macau；週末／noop 安靜。
為何：減少打擾、時間一致。
📨
3. 外發一律草稿
做：電郵／Slack／發帖先 draft。
為何：人把關，防誤寄。
🧾
4. Status ≠ evidence
做：要截圖／URL／mtime。
為何：不信「已完成」自報。
🔒
5. 密碼不入 chat
做：用 Vault（密碼庫）／安全表單。
為何：防洩漏進記憶與記錄。

🧩 Skill（技能）vs Routine（排程／例行工作）

先弄清「怎麼做」與「何時跑」；建議順序：做成功一次 → 存成 Skill → 再自動化成 Routine。

查證聲明（2026-11-01）
依據官方 Skills and routines（頁面 last updated Oct 28, 2026）。介面會改版；不捏造未寫明的按鈕或快捷鍵。

🧩 Skill（技能）

  • 可重用的「怎麼做」說明
  • 含步驟、決策規則、預期輸出、安全邊界
  • 帳戶內各 Bot 可共用；某 Bot 可能需對應 app／登入才用得上

⏰ Routine（排程／例行工作）

  • 指定某個 Bot「何時跑」
  • 排程（例如工作日早上）或事件觸發（Slack／電郵／webhook 等）
  • 雲端執行；筆電可關機
對照Skill（技能）Routine（排程／例行工作）
本質方法／說明書觸發器＋何時執行
問題「要怎麼做這件事？」「何時／因何事跑這流程？」
建議順序先做一次成功 → 存成 Skill → 再自動化成 Routine

官方原文概念：A skill is a reusable set of instructions；a routine tells one Bot when to run。

🛒
1. 套件／市集型
側欄 Connect apps（連接應用） → 發現並安裝支援的 apps 與 packaged skills（套裝技能）。
🔒
2. 私人 Skill 庫
Private skills（私人技能） 為帳戶共用。若某 Bot 找不到：Connect apps → 點標題旁「已連接數量」→ 在 Private skills 為目前這個 Bot啟用。
💾
3. 自己存一條
任務成功後對 Bot 說：「把剛才流程存成名為……的 skill」。要求含：何時用、輸入與權限、步驟、如何驗收、回傳什麼、哪些要批准。
🎥
4. Teach a task（示範教任務）
功能可能逐步開放 一對一對話＋電腦畫面 → Teach a task → 描述目標 → 示範一次 → 停止錄製 → 審閱草稿 Skill → 安全例子測試後再排程。若看不到此控制，改用文字請 Bot 依完成任務建立 Skill。
使用方式
用名稱請 Bot 執行該 Skill。官方寫明：用 @ 呼叫 Bot、群組、Routine、apps。勿捏造未寫明的快捷鍵／斜線指令。

☁️ VM（雲端虛擬機）：全部 bot 共用一部

各 bot 有自己螢幕；檔案／登入共用。持久檔放 /workspace。

🖥️ Your computer（本機）

  • Execution：Ask／Always／Never
  • Route traffic（路由流量）：流量經本機 → 對方見本機 IP
  • 適合：內網、要你地區 IP 的站

☁️ Bot's computer（雲端）

  • Update／Reset／Recover
  • 常見為資料中心 IP（如美國等地）
